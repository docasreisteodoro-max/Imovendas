Área de gestão — demonstração local

Esta versão guarda os anúncios apenas neste navegador. Não é um painel seguro nem sincroniza dados entre dispositivos. Para publicar online, será necessário configurar uma base de dados e autenticação.

Use apenas fotografias reais e autorizadas dos imóveis. Imagens muito grandes podem exceder o espaço do navegador.
